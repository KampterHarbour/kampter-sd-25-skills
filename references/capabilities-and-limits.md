# Seedance 2.5 Capabilities and Limits

## Scope

本页整理自字节跳动官方飞书 Wiki 中的 Seedance 2.5 创作手册，服务于即梦产品中的创作讨论。它不是 API 文档，也不代表任何未在来源中明确出现的接口、计费、并发或自动化能力。

## Official limits used by this skill

| 场景 | 官方范围 |
| --- | --- |
| 标准生成 | 4-30 秒；480p 或 720p |
| 超长模式 | 30-180 秒 |
| 视频延长 | 原视频不超过 30 秒；单次延长 4-30 秒；最终视频最长 60 秒 |
| 参考图片 | 最多 30 张 |
| 参考视频 | 最多 10 个，总时长不超过 30 秒 |
| 参考音频 | 最多 10 个，总时长不超过 30 秒 |

在推荐规格前先识别用户使用的是标准生成、超长模式还是视频延长。不要为了“更专业”而擅自写入超出范围的时长或分辨率。

## Official prompt organization

官方最佳实践将完整提示词组织为：

1. 参数。
2. 素材对应关系。
3. 一句话创意。
4. 全局设定。
5. 带时间戳的分镜。
6. 声音。
7. 负向约束。
8. 全局强化。

这是一套信息组织顺序，不要求每个简单请求机械地保留八个标题。短提示词仍应让模型看清：做什么、用哪些素材、何时发生、怎样拍、怎样听、哪些不能变。

## Material mapping

用户有参考素材时，为每项素材建立稳定标识，并写清单一或主要职责，例如：

- 主体外观与服装参考。
- 首尾帧或构图参考。
- 动作、运镜、节奏或转场参考。
- 场景、美术、材质、光线或色彩参考。
- 台词、音乐、声线、环境声或音效参考。

沿用用户或产品界面已经显示的素材编号。未看到真实素材时，不臆测其内容；先让用户描述，或用占位符并明确需要替换。

## Editing

基础编辑请求使用：

> 目标 + 请求的变化 + 生效时间

高级编辑在此基础上加入标注工具或具体位置。必须区分“只改某个对象/区域/时间段”和“全片统一修改”，否则容易扩大编辑范围。

## Extension

先判断两类意图：

- **无缝续写**：保持主体、动作方向、镜头运动、环境、光线和声音的连续性，再自然发生新动作。
- **有意转场**：明确转场触发点、手法、转场后的新场景或时间，以及需要保留的视觉/声音桥梁。

不要只写“继续视频”。说明从原片结尾的哪个状态接续，以及新增时段内发生什么。

## White-model references

白模工作流按用途分开：

- **粗动作骨架**：主要继承角色动作、调度、机位或运镜；允许重新设计材质、灯光与最终视觉风格。
- **精细渲染参考**：除动作和镜头外，更强调几何、构图、空间关系与细节呈现，减少无意重设计。

先问用户白模是“只借动作和镜头”还是“连构图与空间细节也要保留”。

## Claims this skill must not make

- 不把这份即梦创作手册描述成 Seedance API 规范。
- 不推断未列明的文件格式、文件大小、并发、价格、种子、采样器或接口参数。
- 不承诺提示词必然得到完全一致的角色、文字、物理效果或声音。
- 不把实践模板中的字段误称为平台强制语法。

来源与事实层级见 `source-notes.md`。
