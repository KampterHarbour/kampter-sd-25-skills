# Workflow Router

## Choose a conversation mode

| 信号 | 使用模式 | 首要动作 |
| --- | --- | --- |
| 只有一句想法、不懂术语、说“帮我想” | 快速共创 | 复述意图，提出最多 3 个影响最大的选择 |
| 已给时长、画幅、分镜、镜头或素材职责 | 导演模式 | 整理约束，定位缺口与冲突，直接推进镜头方案 |
| 已有提示词、成片偏差或说“为什么不对” | 提示词诊断 | 对照目标找出最关键的 1-3 个问题，再改写 |

不要用模式名称给用户贴标签。用户在对话中变得更具体时，自然从快速共创转入导演模式。

## Quick co-creation

适用于小白或早期灵感。

1. 用一句话复述“拍什么”和“希望观众有什么感觉”。
2. 只问会改变整条片子的关键问题。通常先问用途/受众、时长、核心风格或叙事变化。
3. 给出有限选项并推荐一个。例如：“如果是产品种草，我更推荐真实生活感；它比纯广告光更容易建立可信度。”
4. 素材存在时，再问每项素材想保留什么；不要先讲复杂的素材编号规则。
5. 信息足够后给第一稿，并把默认选择列为假设。
6. 询问一个针对成片效果的迭代问题，例如“你更想加强高级感，还是加强生活感？”

避免连续追问十几个字段。对方不知道时，给出一个合理建议继续推进。

## Director mode

适用于希望控制镜头、节奏和素材角色的用户。

1. 将输入整理为目标、规格、素材、全局风格、时间轴、声音和约束。
2. 检查时长、素材数量、参考时长与任务模式是否匹配官方范围。
3. 识别镜头层级冲突，例如“固定机位”同时要求“快速环绕”，或同一时段同时发生过多动作。
4. 按叙事因果重排时间轴：建立 -> 推进 -> 转折/展示 -> 收束。
5. 明确每个镜头的主体、可见动作、景别/机位、运镜、环境变化和声音事件。
6. 只对真正不确定的创作决策提问；技术细节可在不改变意图时直接优化。
7. 输出一份主提示词，必要时提供一个策略明显不同的备选。

用户已经提供时间码或 shot list 时，尽量保留结构，只修正冲突和不可执行密度。

## Prompt diagnosis

先要求或提取三项：原提示词、目标效果、实际偏差。用户无法提供成片时，也可以仅诊断文本风险，但要说明无法判断真实生成表现。

按以下顺序定位问题：

1. **任务不清**：生成、编辑、延长或参考素材用途混杂。
2. **目标不清**：只有风格词，没有主体、动作或叙事结果。
3. **时间不清**：动作没有生效时段，或时间段总和与片长不一致。
4. **素材不清**：只说“参考这些”，没有分配外观、动作、镜头、声音等职责。
5. **冲突**：主体、镜头、光线、风格或约束互相打架。
6. **过载**：短时长内塞入过多场景、转场、动作或台词。
7. **连续性弱**：人物、服装、道具、空间方向、光线或声音没有全局锚点。
8. **约束失效**：负向描述过长、抽象，或与正向要求重复冲突。

输出顺序：主要问题 -> 最小修改 -> 完整重写。最小修改尽量保留用户原有创意语言。

## Choose the task workflow

### New generation

建立一句话创意和清晰时间轴。无参考素材时重点控制主体、动作、场景、镜头和声音；有素材时先做素材映射。

### Editing

确认编辑目标、改什么、何时生效、其他内容是否必须保持不变。局部编辑时补充位置或标注信息。不要默认整段重做。

### Extension

确认原片长度和计划延长秒数，检查最终长度。询问无缝续写还是有意转场，然后定义原片末态、接续锚点、新动作和收束状态。

### White model

先区分粗动作骨架与精细渲染参考。明确哪些要继承、哪些允许重设计，再撰写最终视觉、材质、灯光和声音目标。

## Readiness gate

满足以下条件，或已明确采用假设后，即可出第一稿：

- 用户想表达的核心内容和目标效果清楚。
- 任务类型清楚。
- 时长与基本交付方向清楚。
- 主体、关键动作/变化和场景清楚。
- 已提供素材的职责清楚。
- 必须保留和必须避免的要求没有关键冲突。

画幅、镜头、声音或风格并非每次都必须由用户决定；可以基于用途推荐，但要标注为创作选择，不冒充官方默认值。
