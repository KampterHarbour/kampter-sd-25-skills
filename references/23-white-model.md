# White-Model and Previsualization

> Load order: read `00-core-constraints.md` first. Use this page only for white-model, animatic, blocking, or 3D-previsualization references. Read `30-final-review.md` immediately before delivery.

## Choose the reference role

| Reference role | Preserve | Allow to redesign |
| --- | --- | --- |
| Coarse motion skeleton | Action timing, blocking, camera position/path, spatial direction | Character design, materials, lighting, color, final environment |
| Fine rendering reference | Geometry, proportions, composition, occlusion, spatial relationship, action, camera timing | Only explicitly permitted material, lighting, weather, and visual effects changes |

Ask one decisive question when needed: should the reference control only motion/camera, or also composition and spatial detail?

## Coarse-skeleton template

```text
[白模素材]只用于参考角色动作、调度、机位和镜头节奏，不继承灰白材质与未完成背景。保持动作时序和空间方向，将角色重设计为[最终角色]，场景渲染为[环境]，材质、灯光和色彩采用[目标风格]。处理动作接触、重心、衣物和环境反馈，使最终画面不呈现白模质感。
```

## Fine-reference template

```text
以[精细白模/三维预演素材]为几何、构图、空间关系、动作和运镜依据。保留[必须固定的轮廓、比例、位置、遮挡和镜头时序]，在此基础上完成[角色材质、场景材质、灯光、天气、特效和最终风格]。不要无意改变主要几何结构或镜头路径。
```

## Exit criteria

Proceed to `30-final-review.md` when the inheritance boundary is explicit and the prompt specifies both what to keep and what to redesign.
