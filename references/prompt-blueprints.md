# Prompt Blueprints

## Use templates as structure, not ritual

模板用于消除歧义，不是必须原样填满的咒语。简单镜头可以压缩，复杂多素材任务则应保留清晰标题。所有占位符都必须替换或删除。

## General generation blueprint

```text
[参数]
任务：生成视频
时长：[总时长]
分辨率：[仅填写用户选择且产品支持的值]
画幅/交付方向：[用户要求]

[素材对应]
[素材标识]：用于[主体外观/首尾帧/动作/运镜/场景/风格/声音等具体职责]

[一句话创意]
[谁]在[什么场景]中[发生什么关键变化]，最终传达[情绪、卖点或叙事结果]。

[全局设定]
主体：[身份、外观、服装、关键一致性锚点]
环境：[地点、时间、天气、空间关系]
视觉：[媒介/类型、质感、光线、色彩]
摄影：[总体景别策略、机位、运动、节奏]

[时间戳分镜]
00:00-00:0X：[构图与主体初态]；[可观察动作]；[镜头与环境变化]；[声音事件]
00:0X-00:0Y：[动作推进或转折]；[镜头变化]；[连续性锚点]
00:0Y-00:ZZ：[结果/产品展示/情绪收束]；[结束构图与声音落点]

[声音]
台词/旁白：[说话者、准确文本、时间、语气]
音乐：[风格、速度、进入与退出方式]
环境声/音效：[与动作同步的关键声音]

[负向约束]
避免[会直接破坏目标的具体问题]；不要改变[必须保留项]。

[全局强化]
全片保持[人物/服装/产品/空间方向/光线/色彩/镜头语言等关键一致性]。
```

## Material mapping pattern

好的映射应让每项素材有明确职责：

```text
图片1：只参考主角面部、发型和服装，不参考背景。
图片2：参考咖啡杯造型、商标朝向和材质反光。
视频1：参考 00:02-00:05 的手部动作节奏，不复制人物外观。
视频2：参考低机位缓慢环绕的运镜方式。
音频1：使用其轻柔女声语气朗读指定旁白，不沿用原文内容。
```

若用户没有告诉你素材内容，不要生成上述具体描述。改用“请说明图片1最想保留什么”或显式占位符。

## Beginner example

用户意图：用一张咖啡杯产品图做 10 秒竖版新品短片，真实、温暖，不要过度奢华。

```text
[参数]
任务：参考图片生成视频
时长：10秒
画幅：竖版

[素材对应]
图片1：严格参考咖啡杯的造型、颜色与标志位置；不参考原图背景。

[一句话创意]
清晨第一束阳光落在刚冲好的咖啡上，一个简单的端杯动作把困倦的早晨变得温暖而有精神。

[全局设定]
真实生活方式短片。安静的居家厨房，清晨暖阳与自然阴影，色彩干净克制，保留轻微生活痕迹。咖啡杯全片外观一致，质感真实，不过度抛光。

[时间戳分镜]
00:00-00:03：近景，咖啡缓慢注入图片1中的杯子，热气自然上升，晨光从侧后方照入；固定机位，只有液体与热气运动；听到轻柔注水声。
00:03-00:07：一只自然的手进入画面握住杯耳，镜头缓慢跟随端杯动作向上移动，背景轻微虚化；杯子标志方向保持稳定可辨。
00:07-00:10：人物在窗边轻抿一口，神情从困倦变得放松；镜头停在杯子与侧脸的中近景，阳光变亮一点，音乐在呼吸感的尾音中收束。

[声音]
轻柔原声吉他铺底；保留注水、杯子接触桌面和轻微室内环境声；无旁白。

[负向约束]
避免奢华酒店感、夸张金色光效、过度磨皮、杯子造型或标志变化、手指异常、热气遮住产品。

[全局强化]
全片保持咖啡杯造型、颜色、材质和标志位置一致；动作自然，节奏舒缓，呈现可信的清晨生活感。
```

## Editing blueprint

基础公式：**目标 + 修改内容 + 生效时间**。

```text
[任务]
编辑已有视频。

[编辑指令]
在[起止时间]，将[目标对象]的[属性/动作/内容]改为[期望变化]。
位置：[画面区域或用户标注名称，仅在需要时填写]。

[保持不变]
保持[人物身份、其他对象、背景、构图、运镜、时长、声音等]不变。

[结果要求]
变化从[触发点]自然开始，在[结束点]完成；边缘、遮挡、光影与运动连续。
```

示例：

```text
编辑已有视频。在00:04-00:07，将画面右侧桌面上的白色包装盒改为深绿色磨砂包装，保留原有尺寸、透视、商标位置与开盒动作。人物、桌面、背景、镜头运动、声音和其余时间段保持不变。包装颜色在00:04进入镜头时已经正确，遮挡关系和环境反光自然一致。
```

## Extension blueprints

### Seamless continuation

```text
从原视频结尾无缝续写[延长秒数]。承接结尾时[主体姿态、动作方向、机位、镜头速度、环境、光线和声音状态]。随后[新动作及因果变化]。镜头继续[运动方式]，不要重新建立场景或突然改变人物外观。最后停在[收束状态]，声音以[方式]连续并结束。
```

### Intentional transition

```text
从原视频结尾延长[延长秒数]。在[触发动作/物体遮挡/声音点]发生[转场方式]，从[原场景]进入[新场景/新时间]。转场前后用[颜色、形状、动作或声音]形成视觉/听觉桥梁。转场后[新动作与镜头]，最终在[结果]收束。除明确变化外，保持[主体身份或关键物件]一致。
```

## White-model blueprints

### Coarse motion skeleton

```text
[白模素材]只用于参考角色动作、调度、机位和镜头节奏，不继承灰白材质与未完成背景。保持动作时序和空间方向，将角色重设计为[最终角色]，场景渲染为[环境]，材质、灯光和色彩采用[目标风格]。处理动作接触、重心、衣物和环境反馈，使最终画面不呈现白模质感。
```

### Fine rendering reference

```text
以[精细白模/三维预演素材]为几何、构图、空间关系、动作和运镜依据。保留[必须固定的轮廓、比例、位置、遮挡和镜头时序]，在此基础上完成[角色材质、场景材质、灯光、天气、特效和最终风格]。不要无意改变主要几何结构或镜头路径。
```

## Writing rules

- 用可观察的动作替代抽象词：“紧张”改为“呼吸变急，手指停在门把上，迟迟没有按下”。
- 每个短镜头只承担一个主要叙事功能。复杂变化拆到相邻时间段。
- 运镜写起点、方向、速度和落点；只写“电影感运镜”信息不足。
- 台词写准确文本、说话者、语气和时间，避免与镜头动作争抢过多信息。
- 负向约束只保留会破坏目标的高风险项，优先用正向可执行描述建立目标。
- 风格参考与内容参考分开写，避免模型误把背景、人物或动作一并复制。
