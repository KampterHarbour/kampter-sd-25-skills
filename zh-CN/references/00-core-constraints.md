# 核心约束

每个请求都在 SKILL.md 之后立刻读取本文件。只有当任务或需求仍不完整时，才读取 10-intake-and-routing.md。

## 范围

使用本 Skill 讨论和撰写字节跳动当前公开创作手册描述的 Seedance 2.5 工作流提示词。将该手册视为产品创作指南，不是 API 文档。

## 官方范围

| 场景 | 官方范围 |
| --- | --- |
| 常规生成 | 4-30 秒；480p 或 720p |
| 超长模式 | 30-180 秒 |
| 视频延长 | 原视频不超过 30 秒；追加 4-30 秒；最终视频不超过 60 秒 |
| 参考图片 | 最多 30 张 |
| 参考视频 | 最多 10 个；单条目标时长 2-30 秒；总时长不超过 30 秒。页面还注明实际可接受范围为 1.8-30.2 秒。 |
| 参考音频 | 最多 10 个；总时长不超过 30 秒 |

提出时长建议前先分类任务。不得补充官方来源未说明的文件格式、文件大小、价格、并发、随机种子、采样器、API 或界面能力。

## 官方已说明的输入与模式

当前手册明确说明首帧、首尾帧、全能参考和纯音频驱动工作流。其功能交互章节列出全能参考、智能编辑、超长视频和首尾帧模式；能力概览还列出 BGM 移除、创意迁移、局部消除/编辑、空间视角修改、音色参考、多人参考、绿幕编辑、白模控制、视频无缝转场和多宫格分镜。

手册特别说明优化输入的语言包括中文、英语、西班牙语、印尼语和马来语，并覆盖泰语、阿拉伯语、葡萄牙语、越南语、日语和韩语。这些是能力说明，不是对任何单条生成结果的保证。

## 官方提示词骨架

需要结构化提示词时，手册给出的骨架为：

1. 素材描述：按上传顺序标出每个素材及其用途。
2. 一句话概述：主体、地点、事件、题材/风格和特殊运镜。
3. 具体情节描述：按时间轴或故事线写，每段可包含画面、镜头、动作、台词和音效。
4. 结尾全局补充：再次强调贯穿全片的机位、环境、声音、氛围、光影和全局排除项。

本 Skill 可将界面参数置于开头，并把声音和负向约束拆成独立区块。这是为了易读而对同一骨架做的映射，不意味着官方定义了固定语法。

## 提示词顺序

仅在复杂提示词需要结构时按以下顺序组织，空区块直接省略：

1. 参数
2. 素材对应
3. 一句话创意
4. 全局设定
5. 时间戳分镜
6. 声音
7. 负向约束
8. 全局强化

让读者能找到以下答案：发生什么、哪个素材控制什么、每个变化何时发生、画面和声音如何呈现、什么必须稳定。

## 素材纪律

- 保留用户或产品界面提供的素材标识。
- 每个素材只承担一个主要职责：身份、产品造型、构图、动作、镜头、环境、风格、音乐、人声或音效。
- 不推断未见素材内容。询问必须保留什么，或使用明确占位符。
- 分开内容参考和风格参考，避免误把图片中的背景、人物或动作当成必须复制的对象。

## 声明边界

上方范围、明确列出的输入/模式/能力和提示词骨架均可溯源至官方手册。仓库中的路由、模板、示例、提问上限和质检启发式都是本 Skill 的方法。

用户询问出处、版本或官方支持时读取 90-source-notes.md。官方来源没有说明的事实，要直接说明当前手册未指定。

## 不执行

不操作生成网站、不登录、不上传或下载文件、不调用 API、不触发生成、不检查账号状态，也不承诺生成结果。说明边界后继续完成提示词准备。
