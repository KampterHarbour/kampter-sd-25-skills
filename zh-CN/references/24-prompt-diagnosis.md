# 提示词诊断

先读取 00-core-constraints.md。本页仅用于诊断已有提示词或用户报告的生成偏差。重写改变任务类型时，诊断后读取对应任务页。交付重写提示词前读取 30-final-review.md。

## 所需输入

- 原提示词。
- 期望结果。
- 观察到的偏差或怀疑的弱点。

没有结果时，只诊断文本风险，并说明无法确认实际输出行为。

## 按此顺序诊断

| 问题类别 | 检查 | 修复 |
| --- | --- | --- |
| 任务模糊 | 生成、编辑、延长和素材要求混在一起 | 说明一个任务并拆开阶段 |
| 目标模糊 | 只有风格形容词，没有主体、动作或结果 | 加入一句话创意和可见变化 |
| 时间模糊 | 没有生效窗口或时间轴总时长不匹配 | 加入连续时间段 |
| 素材模糊 | 点名素材但没有职责 | 每个素材映射一个职责 |
| 冲突 | 镜头、光线、风格或约束互相不兼容 | 选择主指令或拆分时间段 |
| 过载 | 对当前时长塞入过多场景、转场、动作或台词 | 删除或合并，直到一个主要变化能成立 |
| 连续性漂移 | 身份、服装、产品、空间、光线或声音发生漂移 | 加入全局不变量和连续性锚点 |
| 约束失效 | 负向列表过长、抽象或矛盾 | 只保留高风险约束，并强化正向目标 |

## 诊断交付

按此顺序输出：

1. 主要问题：命名一到三个影响最大的缺陷。
2. 影响：解释它们如何导致结果风险。
3. 最小修改版：保留用户措辞，只改必要部分。
4. 完整重写版：结构化替换有帮助时使用对应任务模板。

不能只给抽象批评。用户没有提供结果时，不能声称知道真实生成结果。

修改后的提示词具备明确任务、可观察结果、受控时间/素材职责且无未解决冲突时，继续读取 30-final-review.md。
